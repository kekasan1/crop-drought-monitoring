# Crop Drought Monitoring & Prediction

Система мониторинга и прогнозирования риска засухи сельскохозяйственных полей на основе спутниковых снимков Sentinel-2 (индекс NDVI) и метеорологических данных Open-Meteo с использованием градиентного бустинга CatBoost.

## Архитектура проекта

- **`app.py`** — интерактивное веб-приложение на Streamlit для мониторинга выбранного участка по координатам (широта/долгота), построения графиков температуры и влажности почвы и оценки вероятности водного стресса.
- **`model_builder.ipynb`** — ноутбук с пайплайном разметки целевой переменной (аномалии вегетационного индекса), обучения модели `CatBoostClassifier` и анализа важности признаков.
- **`build_dataset.py`** — скрипт агрегации временных рядов NDVI со спутника Sentinel-2 и суточных метеоданных в итоговый датасет `final_drought_dataset.csv`.
- **`meteo_archive.py`** — модуль выгрузки исторического архива погоды (температура, осадки, влажность почвы 0–7 см) через Open-Meteo Archive API.
- **`planetary_ndvi.py`** — модуль поиска сцен Sentinel-2 L2A в каталоге Microsoft Planetary Computer STAC и расчета пространственного индекса NDVI.
- **`drought_catboost_model.cbm`** — обученная модель CatBoost.
- **`final_drought_dataset.csv`** — собранный датасет для обучения и валидации.

## Установка и запуск

1. Клонирование репозитория:
```bash
git clone https://github.com/kekasan1/crop-drought-monitoring.git
cd crop-drought-monitoring
```

2. Установка зависимостей:
```bash
pip install -r requirements.txt
```

3. Запуск веб-интерфейса:
```bash
streamlit run app.py
```

## Данные и признаки модели

Для прогнозирования риска засухи используются следующие факторы:
- `temp_max` — максимальная суточная температура (°C)
- `temp_mean` — средняя суточная температура (°C)
- `precip_sum` — суточное количество осадков (мм)
- `soil_moisture_mean` — объемная влажность верхнего слоя почвы (0–7 см, м³/м³)
- `ndvi` — нормализованный вегетационный индекс (Sentinel-2 B08/B04)
